# 前端主题与多语言集成约定

适用范围：SaiAdmin 插件的新增或修改页面、弹窗、表格、图表、表单与播放器控制界面。先检查目标宿主代码，再生成前端；不要假设所有 SaiAdmin 6 项目使用相同变量名或语言目录。

## 生成前确认

- 查阅宿主项目规范、主题入口、CSS/SCSS 语义变量、组件库主题配置和实际切换实现；参考一个正常适配的相邻页面及弹窗。
- 查阅宿主 i18n 初始化、语言资源注册、支持语言列表、语言持久化/切换方式和组件库 locale 配置；确认翻译函数及命名空间。
- 简要记录本次将复用的入口与调用方式。若开发包不含宿主实现，先查集成目标；没有证据时明确集成缺口，不凭空发明接口。

## 主题约束

- 使用宿主已有的页面容器、按钮、表格、表单、提示和排版约定。背景、文本、边框、状态色与主色使用宿主语义 token，透明度和悬浮/禁用状态也须适配。
- 禁止将后台写死为白底黑字或固定深色；禁止通过全局 body、根主题类、全局组件选择器或 !important 覆盖宿主主题。优先 scoped 样式及宿主认可的局部扩展。
- 图表、Canvas 等不能直接继承 CSS 的内容，从宿主主题状态/token 解析颜色，并在主题变化时更新；不能只在挂载时读取一次。
- 用户设计的大屏画布背景、品牌色、数据系列配色属于业务配置，可以保存固定值；编辑器工具栏、属性面板、菜单和弹窗仍跟随宿主。不得为了适配后台主题改写用户文档中的配色。

## 多语言约束

- 使用宿主翻译入口和插件独立命名空间；禁止另建与宿主不同步的 locale 状态或擅自改动全局 fallback/默认语言。
- 所有新增 UI 文案均需翻译：菜单/按钮、字段与表头、placeholder、空态、加载/错误/成功提示、校验、确认框、tooltip、无障碍标签、导出默认名称和组件库控件文案。用户输入、SQL、接口字段标识、品牌名及协议常量不强制翻译。
- 为宿主实际支持的语言提供对应资源，复用已有公共词条；不把原文或键名暴露给用户。使用占位插值和宿主日期/数字格式化，避免拼接固定语序。
- 表头、选项、规则和状态提示使用响应式翻译或在展示时求值；不能在模块加载或 setup 时把 t() 结果保存成不会更新的常量。
- 用户保存的标题、预设内容与业务数据不随后台语言切换被重写；只切换编辑器标签及默认展示文案。

## 安装与验收

语言文件、注册代码及主题适配必须随发行 ZIP 到达宿主。优先使用宿主支持的插件注册/合并机制；安装器只复制插件目录时，不得只修改开发宿主 src/locales 就认为插件可安装。必要的额外接入由安装/升级生命周期自动完成，按 [自动接入与卸载](automatic-integration.md) 实现；正常安装步骤不得要求用户运行接入脚本或手工改文件。不能静默覆盖共享语言文件，卸载仅清理插件拥有的资源和片段。

至少验证：

1. 宿主浅色/深色下的页面、弹窗、表格、表单及图表；若宿主支持自定义主色，切换后核对插件主色。
2. 不刷新页面切换宿主语言，核对静态及动态文案、校验/错误提示、日期数字、无障碍标签；使用较长译文检查溢出。
3. 最终 ZIP 全新安装和旧版升级后，无需手动接入即词条可用、无缺失键；切换语言/主题不丢失未保存业务输入，不修改画布配置。卸载后无悬空导入，宿主仍可构建。
4. 记录已验证主题和语言。没有相应宿主能力的项目标记不适用并说明依据；环境不足的项目标记未测。
